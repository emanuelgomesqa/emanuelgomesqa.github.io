Endpoint Oficial Brasil (Totalização)

https://resultados.tse.jus.br/oficial/ele2026/545/dados-simplificados/br/br-c0001-e000545-r.json

* Nota: Durante a noite de eleição, o TSE pode aplicar políticas restritivas de CORS no navegador. Em ambiente local/produção, utiliza-se um backend/proxy para consultar o JSON a cada minuto.

Dicionário Principais Parâmetros TSE

  • pst: Porcentagem das seções totalizadas (% de apuração)
  • s: Total de seções eleitorais
  • st: Seções totalizadas
  • cand: Array com candidatos e votos (n, vap, pvap)
  • vv: Votos Válidos | van: Votos Anulados
  • vb: Votos em Branco | tvn: Total Votos Nulos

Como ignorar CORS usando Node.js/Express Proxy

// Exemplo simples de Proxy Server em Node.js
const express = require('express');
const fetch = require('node-fetch');
const app = express();

app.get('/api/tse-2turno', async (req, res) => {
  try {
    const response = await fetch('https://resultados.tse.jus.br/oficial/ele2026/545/dados-simplificados/br/br-c0001-e000545-r.json');
    const data = await response.json();
    res.json(data);
  } catch (err) {
    res.status(500).json({ error: 'Erro ao conectar ao TSE' });
  }
});
